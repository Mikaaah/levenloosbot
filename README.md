# 🎮 LEVENLOOS Bot

The official Discord bot for the **LEVENLOOS** gaming community.

A custom modular Discord bot built with Python and discord.py, replacing
multiple third-party bots with one integrated system.

## ✨ Features

### 🎮 Game Management
- Create game channels and roles
- Archive and restore games
- Community game voting
- Automatic role/channel synchronization
- Temporary role claim buttons

### ⭐ Levels & XP
- Message XP
- Voice XP
- Invite rewards
- Reaction rewards
- Game vote rewards
- Leaderboards
- Level roles

### 🎭 Role System
- Game roles
- Genre roles
- Level-locked roles
- Color roles
- Gradient role progression

### 📊 Server Statistics
- Weekly messages
- Active members
- Voice activity
- Most active game
- Most active player
- Live server statistics

### 🎂 Birthdays
- Member birthdays
- Birthday announcements
- Congratulation rewards

### 🛡️ Moderation
- Private action log
- Deleted and edited message logging
- Ban/unban logging
- Timeout logging
- Role and channel change logging

### 🧩 Modular Architecture
Modules can be loaded, unloaded and reloaded without restarting the bot.

## 🛠️ Built With

- Python
- discord.py
- SQLite
- aiosqlite
